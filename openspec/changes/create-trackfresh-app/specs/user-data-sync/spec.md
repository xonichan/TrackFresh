# Spec Delta

## Purpose

Хранение и синхронизация данных пользователя через Firebase Firestore с привязкой продуктов к учётной записи.

## ADDED Requirements

### Requirement: Аутентификация пользователя
Система SHALL обеспечивать аутентификацию пользователя через Firebase Authentication.

#### Scenario: Вход в приложение
- **WHEN** пользователь вводит учётные данные (email/пароль или Google-аккаунт)
- **THEN** система аутентифицирует пользователя и загружает его данные

#### Scenario: Регистрация нового пользователя
- **WHEN** пользователь проходит регистрацию
- **THEN** система создаёт учётную запись в Firebase Auth и инициализирует профиль в Firestore

### Requirement: Хранение продуктов в Firestore
Система SHALL хранить данные продуктов пользователя в Firestore по пути `users/{userId}/products`.

#### Scenario: Сохранение продукта
- **WHEN** пользователь добавляет продукт
- **THEN** данные сохраняются в Firestore по пути `users/{userId}/products/{productId}`

#### Scenario: Загрузка списка продуктов
- **WHEN** пользователь открывает приложение
- **THEN** система загружает список продуктов из Firestore и отображает его

### Requirement: Офлайн-доступ
Система SHALL обеспечивать доступ к данным при отсутствии сети с последующей синхронизацией.

#### Scenario: Работа без сети
- **WHEN** устройство не имеет подключения к интернету
- **THEN** пользователь может просматривать ранее загруженные продукты и добавлять новые локально

#### Scenario: Синхронизация при восстановлении сети
- **WHEN** подключение к сети восстанавливается
- **THEN** локальные изменения автоматически синхронизируются с Firestore

### Requirement: Настройки пользователя
Система SHALL хранить настройки пользователя в Firestore по пути `users/{userId}/settings`.

#### Scenario: Сохранение настроек
- **WHEN** пользователь изменяет настройки уведомлений или предпочтения
- **THEN** настройки сохраняются в Firestore и применяются на всех устройствах пользователя
