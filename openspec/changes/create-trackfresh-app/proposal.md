# Proposal

## Why

Пользователям не хватает простого инструмента для отслеживания сроков годности продуктов и лекарств дома. Просроченные товары приводят к потерям денег и риску для здоровья. Существующие решения перегружены или неудобны. TrackFresh решает эту проблему, объединяя ручной ввод, OCR-сканирование упаковки и push-уведомления в минималистичном Android-приложении.

## What Changes

- Создание мобильного приложения на React Native для Android
- Реализация ручного добавления продуктов с полями: название, дата производства, срок годности, категория (продукт/лекарство)
- Интеграция OCR (ML Kit) для сканирования фотографий упаковки и автоматического извлечения данных
- Список продуктов с сортировкой по сроку годности и визуальной индикацией статуса (свежий/истекает скоро/просрочен)
- Push-уведомления о скором истечении срока годности с настраиваемой частотой
- Хранение данных в Firebase Firestore, привязка к учётной записи пользователя
- Экран настроек: частота уведомлений, категории по умолчанию, управление данными

## Capabilities

### New Capabilities

- `product-management`: Добавление, редактирование, удаление и просмотр продуктов/лекарств. Ручной ввод и OCR-сканирование упаковки. Список с сортировкой и фильтрацией по сроку годности.
- `expiration-notifications`: Push-уведомления о скором истечении срока годности. Настраиваемая частота и время отправки. Интеграция с Firebase Cloud Messaging.
- `user-data-sync`: Хранение и синхронизация данных пользователя через Firebase Firestore. Привязка продуктов к учётной записи.

### Modified Capabilities

_Нет — проект создаётся с нуля._

## Impact

- Новая кодовая база React Native с зависимостями: react-native, ML Kit (OCR), Firebase (Firestore, FCM, Auth)
- Новые Firebase-коллекции: `users/{userId}/products`
- Новое Android-приложение — нет влияния на существующие системы
