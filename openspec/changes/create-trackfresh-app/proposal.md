# Proposal

## Why

Пользователям не хватает простого инструмента для отслеживания сроков годности продуктов и лекарств дома. Просроченные товары приводят к потерям денег и риску для здоровья. Существующие решения перегружены или неудобны. TrackFresh решает эту проблему, объединяя ручной ввод, OCR-сканирование упаковки и напоминания в минималистичном Android-приложении.

## What Changes

- Создание мобильного приложения на React Native для Android
- Ручное добавление продуктов: название, категория (продукт/лекарство), срок годности и необязательная дата производства
- OCR-сканирование упаковки через ML Kit с предзаполнением формы
- Список продуктов с сортировкой по сроку годности и цветовой индикацией статуса
- Напоминания о скором истечении срока годности
- Данные хранятся в PostgreSQL; клиент работает через HTTP API (`api/`, спека `data-api`) — прямого доступа к базе у приложения нет
- Аутентификация через Firebase Authentication; идентификатор Firebase связывает устройство с профилем на сервере
- Экран настроек: частота напоминаний, время отправки, период предупреждения

## Capabilities

### New Capabilities

_Нет — поведение уже описано действующими спеками `product-management`, `expiration-notifications`, `user-data-sync` и `data-api`. Это изменение реализует их на клиенте и требований не меняет._

### Modified Capabilities

_Нет._

## Impact

- Новый проект React Native (Expo prebuild + dev-client) с зависимостями: react-navigation, ML Kit (OCR), Firebase Auth, клиент HTTP API
- Приложение зависит от доступности API по приватному адресу `192.168.3.69` — вне домашней сети сервис недоступен
- Работа без сети не поддерживается: локального хранилища нет
- Рассылка напоминаний по расписанию на сервере — отдельное изменение; в этом объёме только локальные напоминания на устройстве
- iOS вне объёма
