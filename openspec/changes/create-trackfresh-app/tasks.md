# Tasks

## 1. Инициализация проекта

- [ ] 1.1 Создать React Native проект через Expo (`npx create-expo-app TrackFresh`), запустить `npx expo start` и убедиться, что приложение запускается на Android
- [ ] 1.2 Установить зависимости: `@react-navigation/native`, `@react-navigation/bottom-tabs`, `@react-navigation/stack`, `react-native-screens`, `react-native-safe-area-context` и убедиться, что навигация собирается без ошибок
- [ ] 1.3 Настроить Firebase: добавить `@react-native-firebase/app`, `@react-native-firebase/auth`, `@react-native-firebase/firestore`, создать проект в Firebase Console, добавить `google-services.json` и убедиться, что приложение подключается к Firebase
- [ ] 1.4 Установить OCR-зависимость `@react-native-ml-kit/text-recognition` и убедиться, что модуль импортируется без ошибок

- [ ] 3.1 Реализовать экран входа/регистрации с поддержкой email/пароль и Google Sign-In; убедиться, что пользователь может зарегистрироваться и войти

- [ ] 4.2 Реализовать список продуктов на главном экране с сортировкой по сроку годности и цветовой индикацией (зелёный/жёлтый/красный); убедиться, что статусы отображаются корректно
- [ ] 4.3 Добавить фильтрацию списка по категории (все/продукты/лекарства); убедиться, что фильтр работает
- [ ] 4.4 Реализовать экран деталей продукта и редактирование полей; убедиться, что изменения сохраняются в Firestore
