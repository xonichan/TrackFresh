# Spec Delta

## ADDED Requirements

### Requirement: Отметка времени изменения в ответе
API SHALL включать в каждый продукт момент последнего изменения `updated_at` в формате ISO 8601, чтобы клиент мог сравнить его со временем локальной правки.

#### Scenario: Продукт в ответе содержит время изменения
- **WHEN** клиент получает продукт при создании, чтении списка или изменении
- **THEN** в ответе есть `updated_at` в формате ISO 8601 с часовым поясом

#### Scenario: Изменение обновляет время
- **WHEN** продукт изменяется через API
- **THEN** `updated_at` становится больше, чем до изменения

### Requirement: Идемпотентное создание продукта
API SHALL принимать необязательный идентификатор продукта от клиента и при повторе того же запроса не создавать второй продукт.

#### Scenario: Создание с идентификатором клиента
- **WHEN** приходит создание продукта с идентификатором, которого ещё нет
- **THEN** продукт сохраняется с этим идентификатором

#### Scenario: Повтор того же идентификатора
- **WHEN** повторно приходит создание с уже существующим идентификатором того же профиля
- **THEN** API возвращает существующий продукт, а не создаёт второй

#### Scenario: Идентификатор занят другим профилем
- **WHEN** приходит создание с идентификатором, принадлежащим другому профилю
- **THEN** API отвечает 409 и не изменяет чужие данные
