# Proposal

## Why

Приложение существует только для Android, и чтобы посмотреть список или добавить продукт, нужен телефон с установленной dev-сборкой. За компьютером — а домашние запасы чаще проверяют именно там — продукт недоступен вовсе. Веб-версия снимает это ограничение и не требует установки.

## What Changes

- Появляется веб-версия с полным набором операций: вход, список с фильтром и цветовой индикацией, добавление, правка, удаление, настройки.
- Веб-версия собирается из того же кода, что и Android-приложение (Expo web, `react-native-web`), а не пишется заново.
- API начинает раздавать файлы веб-версии: интерфейс и запросы к данным идут с одного адреса, отдельный сервер и настройка CORS не нужны.
- Вход в веб-версии — Firebase Authentication через веб-SDK (email/пароль и Google), потому что нативная библиотека `@react-native-firebase/auth` в браузере не работает.
- OCR-сканирование упаковки и локальные напоминания остаются только на телефоне: ML Kit и планировщик уведомлений в браузере недоступны.
- **BREAKING** для области: Non-Goal «Web-версия приложения» из `create-trackfresh-app` отменяется.

## Capabilities

### New Capabilities

- `web-app`: работа с продуктами и настройками из браузера — вход, список, добавление, правка, удаление, разметка статуса срока; без сканирования упаковки и без напоминаний.

### Modified Capabilities

- `data-api`: API отдаёт файлы веб-версии с того же адреса, что и данные.

## Impact

- `api/`: раздача статических файлов и отдача `index.html` для клиентских маршрутов; проверка токена и изоляция данных не меняются.
- `mobile/`: включение платформы web (`react-dom`, `react-native-web`, метро-рантайм), разделение модулей по платформам — аутентификация, сканирование, напоминания.
- Новая зависимость: Firebase JS SDK для веб-аутентификации.
- Риск: код, общий для двух платформ, усложняет отладку — часть модулей существует в двух вариантах.
- Вне объёма: офлайн-работа в браузере, push-уведомления в браузере, отдельный лендинг, доступ к API из интернета (это `expose-api-remotely`).
