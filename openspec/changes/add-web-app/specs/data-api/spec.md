# Spec Delta

## ADDED Requirements

### Requirement: Раздача веб-интерфейса
API SHALL отдавать файлы веб-версии с того же адреса, на котором принимает запросы к данным.

#### Scenario: Запрос главной страницы
- **WHEN** браузер запрашивает корень адреса API
- **THEN** возвращается страница веб-версии

#### Scenario: Клиентский маршрут
- **WHEN** браузер открывает адрес веб-версии, которого нет среди файлов, но который нужен интерфейсу
- **THEN** возвращается главная страница, чтобы переход по ссылке не давал ошибку

### Requirement: Запросы к данным не перехватываются веб-интерфейсом
API SHALL отдавать данные по своим маршрутам независимо от наличия файлов веб-версии.

#### Scenario: Существующий маршрут данных
- **WHEN** клиент запрашивает список продуктов или настройки
- **THEN** возвращается ответ данных, а не файл страницы

#### Scenario: Несуществующий маршрут данных
- **WHEN** клиент запрашивает продукт, которого нет
- **THEN** возвращается прежний ответ «не найдено», а не страница веб-версии
