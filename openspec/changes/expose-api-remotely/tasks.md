# Tasks

## 1. Удостоверяющий центр и сертификаты

- [ ] 1.1 Выпустить локальный корневой сертификат (openssl) и серверный сертификат с `subjectAltName = IP:<внешний адрес>`; убедиться через `openssl x509 -text`, что SAN содержит именно IP, а не CN
- [ ] 1.2 Проверить цепочку: `openssl verify -CAfile ca.crt server.crt`; убедиться, что проверка проходит и срок действия не истёк

## 2. Обратный прокси

- [ ] 2.1 Поднять прокси (nginx или Caddy) с TLS на внешнем порту и передачей запросов на локальный порт API; убедиться, что `curl --cacert ca.crt https://<адрес>/health` возвращает `{"status":"ok"}`
- [ ] 2.2 Настроить порт, отвечающий только перенаправлением на HTTPS; убедиться, что запрос по HTTP не возвращает тело ответа API
- [ ] 2.3 Ограничить частоту запросов с одного адреса; убедиться, что после превышения приходит 429, а в пределах лимита запросы проходят

## 3. Доступ извне

- [ ] 3.1 Настроить на роутере перенаправление внешнего порта на `192.168.3.69`; убедиться, что запрос из мобильной сети (не из домашнего Wi-Fi) доходит до `/health`
- [ ] 3.2 Убедиться, что прямой доступ к порту API снаружи закрыт: запрос на локальный порт по внешнему адресу не проходит
- [ ] 3.3 Запустить прокси и API как службы с автоперезапуском; убедиться, что после перезагрузки сервера `/health` отвечает без ручных действий

## 4. Клиент

- [ ] 4.1 Положить корневой сертификат в ресурсы приложения и настроить `network_security_config.xml` на доверие только ему для внешнего адреса; убедиться, что приложение подключается к API по HTTPS
- [ ] 4.2 Вынести внешний базовый адрес в конфигурацию сборки; убедиться, что смена адреса не требует правок в коде экранов
- [ ] 4.3 Убедиться, что при подмене сертификата (или использовании самоподписанного без совпадения) приложение не подключается и показывает понятную ошибку, а не пустой список

## 5. Документация

- [ ] 5.1 Описать в `docs/remote-access.md`: выпуск и продление сертификатов, конфигурацию прокси, порт на роутере, где лежит базовый адрес в приложении; убедиться, что команды из документа выполняются как написано
