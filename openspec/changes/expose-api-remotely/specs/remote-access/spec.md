# Spec Delta

## Purpose

Доступ к API TrackFresh из внешней сети: HTTPS вместо открытого HTTP, доверие приложения только собственному сертификату сервера и ограничение частоты запросов на публичной точке входа.

## ADDED Requirements

### Requirement: Доступ только по HTTPS
Система SHALL обслуживать внешние запросы к API только по HTTPS и не передавать данные по открытому HTTP.

#### Scenario: Запрос по HTTPS
- **WHEN** клиент обращается к внешнему адресу по HTTPS с доверенным сертификатом
- **THEN** запрос передаётся локальному API и обрабатывается как обычно

#### Scenario: Запрос по HTTP
- **WHEN** клиент обращается к тому же адресу по открытому HTTP
- **THEN** данные не передаются, соединение перенаправляется на HTTPS либо отклоняется

### Requirement: Доверие приложения к серверу
Приложение SHALL принимать только серверный сертификат, подписанный ожидаемым удостоверяющим центром, и отклонять любой другой.

#### Scenario: Серверный сертификат совпадает
- **WHEN** приложение подключается к API и сертификат подписан ожидаемым центром
- **THEN** соединение устанавливается

#### Scenario: Другой или просроченный сертификат
- **WHEN** сервер предъявляет сертификат от другого центра, самоподписанный без совпадения или просроченный
- **THEN** приложение не устанавливает соединение и показывает понятную ошибку вместо пустого списка

### Requirement: Ограничение частоты запросов
Система SHALL ограничивать число запросов с одного адреса на публичной точке входа.

#### Scenario: Превышение частоты
- **WHEN** с одного адреса приходит больше запросов, чем разрешено за интервал
- **THEN** система отвечает 429 и не передаёт запрос дальше

#### Scenario: Обычная нагрузка
- **WHEN** число запросов с адреса в пределах разрешённого
- **THEN** запросы обрабатываются без ограничений
