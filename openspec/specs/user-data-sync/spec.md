# user-data-sync Specification

## Purpose

Хранение данных пользователя в PostgreSQL с привязкой продуктов к учётной записи Firebase.

## Requirements

### Requirement: Аутентификация пользователя
Система SHALL обеспечивать аутентификацию пользователя через Firebase Authentication и хранить идентификатор Firebase в профиле пользователя отдельным уникальным полем.

#### Scenario: Вход в приложение
- **WHEN** пользователь вводит учётные данные (email/пароль или Google-аккаунт)
- **THEN** система аутентифицирует пользователя и загружает его данные

#### Scenario: Регистрация нового пользователя
- **WHEN** пользователь проходит регистрацию
- **THEN** система создаёт учётную запись в Firebase Auth и заводит профиль в PostgreSQL с идентификатором Firebase

### Requirement: Хранение продуктов в PostgreSQL
Система SHALL хранить продукты пользователя в PostgreSQL, привязывая каждую запись к идентификатору пользователя.

#### Scenario: Сохранение продукта
- **WHEN** пользователь добавляет продукт
- **THEN** данные сохраняются в таблице `products` со ссылкой на пользователя

#### Scenario: Загрузка списка продуктов
- **WHEN** пользователь открывает приложение
- **THEN** система загружает список его продуктов из PostgreSQL и отображает его

### Requirement: Настройки пользователя
Система SHALL хранить настройки пользователя в строке таблицы `user_settings`, связанной с пользователем.

#### Scenario: Сохранение настроек
- **WHEN** пользователь изменяет настройки уведомлений или предпочтения
- **THEN** настройки сохраняются и применяются на всех устройствах пользователя
