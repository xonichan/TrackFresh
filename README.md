# TrackFresh

Android-приложение для отслеживания сроков годности продуктов и лекарств.
Слоган: «Track your food freshness». Домен: trackfresh.app.

## Что делает

- Ручное добавление продуктов и лекарств: название, категория, срок годности,
  необязательная дата производства.
- OCR-сканирование упаковки (ML Kit) с предзаполнением формы.
- Список с сортировкой по сроку и цветовой индикацией: свежий / истекает скоро / просрочен.
- Локальные напоминания о скором истечении; частота, время и период предупреждения настраиваются.
- Работа без сети: данные хранятся на устройстве, изменения уходят на сервер при появлении связи.

## Устройство проекта

| Каталог | Что это |
|---|---|
| `mobile/` | Android-приложение и веб-версия на React Native (Expo prebuild + dev-client, общий код) |
| `api/` | HTTP-сервис на Express + TypeScript, единственный путь приложения к данным; он же раздаёт веб-интерфейс |
| `migrations/` | SQL-миграции схемы PostgreSQL |
| `docs/` | `data-model.md` — схема и изоляция данных; `api.md` — контракт API; `web-check.md` — как проверить веб-версию |
| `openspec/` | спеки и изменения (spec-driven разработка) |

Данные лежат в PostgreSQL; доступ к ним идёт только через API. Вход — Firebase Authentication
(ID-токен в заголовке), идентификатор Firebase связывает устройство с профилем на сервере.
Один и тот же код работает на телефоне и в браузере; в браузере недоступны сканирование
упаковки и напоминания — они требуют нативных библиотек.

## Состояние

Серверная часть реализована и покрыта тестами (36 — API, 41 — логика клиента).
Клиент написан и собирается для телефона и браузера, но на устройстве ещё не запускался:
не было доступа к Android SDK. Внешнего доступа по HTTPS нет, фоновая рассылка напоминаний
не сделана. Подробности — в `openspec/changes/`.

## Быстрый старт

```bash
# сервер
cd api && npm install && npm run build && npm start

# приложение (нужен Android SDK)
cd mobile && npm install && npx expo run:android

# веб-версия: собрать интерфейс туда, откуда его раздаёт API
cd mobile && npm run build:web
```

Требования и переменные окружения — в `api/` и `mobile/README.md`.
